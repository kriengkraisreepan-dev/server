# คู่มือตั้งค่ากล่องควบคุมไฟโต๊ะ

## เตรียมก่อนเริ่ม

- เปิดกล่องควบคุมและรอประมาณ 10 วินาที
- ตรวจว่ากล่องเชื่อมต่อ Wi-Fi 2.4 GHz
- คอมพิวเตอร์อาจใช้ Wi-Fi 5 GHz ได้ แต่ต้องใช้เราเตอร์เดียวกัน
- เตรียมเลขอุปกรณ์ เช่น `192.168.1.191` และรหัสอุปกรณ์

## วิธีตั้งค่า

1. เข้าระบบด้วยบัญชีเจ้าของร้าน
2. เลือก **Hardware Manager**
3. กด **เริ่มตั้งค่ากล่องควบคุม**
4. อ่านรายการเตรียมพร้อม แล้วกด **เริ่มตั้งค่า**
5. กรอก **เลขอุปกรณ์ในเครือข่าย** แล้วกด **ค้นหาและตรวจสอบ**
6. เมื่อระบบแจ้งว่าผ่าน ให้กรอก **รหัสอุปกรณ์**
7. ตรวจว่าไม่มีโต๊ะใช้งาน แล้วทำเครื่องหมายยืนยัน ระบบจะปิด Relay ทุกช่องชั่วคราว
8. อ่านคำเตือนและทำเครื่องหมายว่าทดสอบได้อย่างปลอดภัย
9. กด **ทดสอบ** ทีละช่อง ระบบจะเปิดประมาณ 1 วินาทีแล้วปิดเอง
10. ถ้าเกิดเหตุผิดปกติ กด **ปิด Relay ทั้งหมด**
11. ตั้งชื่อที่จำง่าย เช่น “กล่องควบคุมโซนหลัก” แล้วกดบันทึก

## ถ้ายังไม่พบกล่อง

1. ตรวจว่าไฟกล่องติด
2. รอให้กล่องเชื่อม Wi-Fi
3. ตรวจว่าคอมพิวเตอร์กับกล่องใช้เราเตอร์เดียวกัน
4. ตรวจเลขอุปกรณ์แล้วลองใหม่

ห้ามเติม `http://` หรือข้อความต่อท้ายเลขอุปกรณ์

## ข้อความสถานะ

- **ผ่าน**: โปรแกรมติดต่อและอ่านข้อมูลได้
- **ควรตรวจสอบ**: ใช้งานได้ แต่มีบางช่องที่ข้ามหรือ firmware รุ่นใหม่
- **ไม่ผ่าน**: ทำตามคำแนะนำบนหน้าจอแล้วลองใหม่

ผล “คำสั่งเปิดและปิดทำงาน” ยืนยันการสั่งงานของโปรแกรมเท่านั้น ควรตรวจหลอดไฟและสายต่อจริงก่อนเปิดร้าน
