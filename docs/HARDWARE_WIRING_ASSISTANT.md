# Hardware Wiring Assistant

Hardware Wiring Assistant อยู่ใน Hardware Manager และใช้ตรวจสาย ESP32–Relay ทีละช่องโดยไม่แก้ GPIO mapping หรือการผูกโต๊ะ ระบบรองรับ Relay 2, 4 และ 8 ช่องตามจำนวนจริงของกล่อง

## ความปลอดภัยก่อนเริ่ม

1. ปิดโต๊ะทั้งหมดผ่าน workflow ปกติและตรวจว่าไม่มี Active Table Session ที่ผูกกับกล่อง
2. ถอดโหลดไฟบ้านออกจาก Relay ทุกช่อง ใช้เฉพาะไฟแรงดันต่ำระหว่างทดสอบ
3. ตรวจว่า Relay ทุกช่อง OFF และยืนยันคำเตือนทั้งห้าข้อในหน้าจอ
4. Setup Mode, Wi-Fi provisioning และ USB Flasher ต้องไม่ทำงานอยู่

Backend เป็นผู้กำหนด pulse 1,000 ms เปิดทีละช่อง และปิดเฉพาะช่องที่เปิดเองใน cleanup ระบบไม่ใช้ `all/off` และ Browser ส่ง GPIO หรือ pulse duration เองไม่ได้

## ขั้นตอนตรวจ

เลือก **ตรวจสอบการต่อสาย** บน Device Card ตรวจรายละเอียดกล่อง อ่านคำเตือน ดูผังสาย แล้วกดทดสอบทีละช่อง หลังได้ยินเสียงคลิกหรือเห็น LED ให้เลือก ถูกต้อง, ไม่ถูกต้อง, ไม่แน่ใจ หรือข้ามก่อน หากไม่ถูกต้องให้ระบุ IN ที่ทำงานจริง ข้อมูลนี้ใช้วินิจฉัยเท่านั้นและไม่แก้ mapping อัตโนมัติ

ถ้าปิด Relay ไม่สำเร็จ หน้าจอจะแสดงคำเตือนสีแดงและล็อก session ห้ามทดสอบต่อ ให้ตัดไฟแรงดันต่ำหรือสาย USB ของ Relay controller ทันที แล้วตรวจอุปกรณ์ด้วยผู้ติดตั้งที่มีความรู้ ห้ามสั่ง all-off เพื่อกลบข้อผิดพลาด

เมื่อครบแล้วกดบันทึกและ **พิมพ์แผนผังสาย** Wiring Profile ผูกกับ Device ID ไม่หายเมื่อ IP เปลี่ยน รองรับหลาย ESP32 แต่ค่าเริ่มต้นจำกัด Wiring Test ทั่วระบบครั้งละหนึ่ง session

เมื่อเปลี่ยน Relay board, Relay Count, Device ID หรือ Hardware Standard สถานะจะเป็น `REVERIFY_REQUIRED` และต้องตรวจใหม่ทุกช่อง
