## 4. อนุมัติ

ข้าพเจ้าในฐานะ Production Approver อนุมัติให้ดำเนินการ Production Key Ceremony ตามที่ระบุไว้ในเอกสารนี้และตาม `docs/PRODUCTION_KEY_CEREMONY.md` ทุกประการ รับทราบว่า:

- Private Key จะถูกสร้างบนเครื่อง Offline เท่านั้น และจะไม่ถูกคัดลอกเข้าเครื่องที่ต่อเน็ตใดๆ
- Passphrase ของ Private Key จะไม่ถูกบันทึกที่ใดนอกจากความจำของผู้ที่ได้รับมอบหมายให้ทราบ
- ระบบจะ enroll เฉพาะ Public Key, วันหมดอายุ และ fingerprint เข้า Manager source ผ่าน reviewed change เท่านั้น
- ต้องทำ recovery drill (ตรวจว่าสื่ออ่านได้จริง) อย่างน้อยปีละครั้ง
