# มาตรฐานป้ายสาย Lucky Hardware LHS-1.0

| Relay | ESP32 | Relay input | ใช้กับ board |
|---|---|---|---|
| R1 | GPIO13 | IN1 | 2/4/8 ช่อง |
| R2 | GPIO14 | IN2 | 2/4/8 ช่อง |
| R3 | GPIO16 | IN3 | 4/8 ช่อง |
| R4 | GPIO17 | IN4 | 4/8 ช่อง |
| R5 | GPIO18 | IN5 | 8 ช่อง |
| R6 | GPIO19 | IN6 | 8 ช่อง |
| R7 | GPIO25 | IN7 | 8 ช่อง |
| R8 | GPIO26 | IN8 | 8 ช่อง |

ติดป้ายทั้งสองปลายในรูป `R1 / GPIO13 / IN1` สีสายเป็นเพียงตัวช่วยและห้ามใช้สีเป็นหลักฐานเดียว ก่อนแก้สายต้องตัดไฟบ้านและไฟเลี้ยง Relay ตามขั้นตอนความปลอดภัย
