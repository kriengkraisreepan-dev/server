# คู่มือเริ่มต้นสำหรับ Lucky Relay Controller v1.0

คู่มือนี้สำหรับผู้ที่ไม่เคยใช้ ESP32, VS Code, PlatformIO หรือเขียนโปรแกรมมาก่อน อ่านและทำตามทีละข้อ ห้ามต่อไฟบ้านเข้ากับ Relay เอง หากไม่ใช่ช่างไฟฟ้าที่มีคุณสมบัติเหมาะสม

## สิ่งที่ระบบทำ

```text
Windows PC → สาย USB → ESP32 → Relay → ไฟโต๊ะ
Windows PC → Wi‑Fi → ESP32 → Relay → ไฟโต๊ะ
```

```mermaid
flowchart LR
  PC[คอมพิวเตอร์ Windows] -->|USB สำหรับลงโปรแกรม| ESP[ESP32]
  PC -->|HTTP ผ่าน Wi‑Fi| ESP
  ESP -->|GPIO 13,14,16,17,18,19,25,26| R[Relay 2/4/8 ช่อง]
  R --> L[วงจรไฟโต๊ะ: ให้ช่างไฟติดตั้ง]
```

## คำศัพท์ง่าย ๆ

| คำ | ความหมายแบบง่าย |
|---|---|
| ESP32 | บอร์ดคอมพิวเตอร์ขนาดเล็ก ใช้สั่ง Relay |
| Firmware | โปรแกรมที่อยู่ใน ESP32 |
| VS Code | โปรแกรมเปิดและแก้ไขโครงการบนคอมพิวเตอร์ |
| PlatformIO | เครื่องมือใน VS Code สำหรับสร้างและอัปโหลด Firmware |
| Relay | สวิตช์ที่ ESP32 สั่งให้เปิด/ปิดได้ |
| Serial Monitor | หน้าต่างอ่านข้อความที่ ESP32 รายงานผ่านสาย USB |
| COM Port | ชื่อช่อง USB ของ ESP32 ใน Windows เช่น COM3 |

## อุปกรณ์ที่ต้องมี

- คอมพิวเตอร์ Windows พร้อมอินเทอร์เน็ต
- ESP32 DevKitC V4 หรือ ESP32-WROOM-32E แบบ 38 ขา
- สาย USB **ที่ส่งข้อมูลได้** (สายชาร์จอย่างเดียวใช้ไม่ได้)
- Relay 5V แบบ Active LOW จำนวน 2, 4 หรือ 8 ช่อง
- แหล่งจ่ายไฟที่เหมาะสมสำหรับ Relay และ ESP32
- ผู้ดูแลระบบที่มี Wi‑Fi name, password และ Device Key

> ห้ามจ่ายไฟให้คอยล์ Relay จากขา 3.3V ของ ESP32 และห้ามต่อไฟบ้านในขั้นตอนทดสอบนี้

## แผนการทำงาน

1. ติดตั้ง VS Code
2. ติดตั้ง PlatformIO
3. เปิดโฟลเดอร์ `firmware`
4. Build
5. ต่อ ESP32 ด้วย USB
6. Upload
7. ดู Serial Monitor
8. ทดสอบ API และ Relay โดยยังไม่ต่อไฟบ้าน

### ✓ Expected Result

คุณทราบว่า ESP32 เป็นตัวรับคำสั่ง, Relay เป็นสวิตช์ และไฟบ้านต้องติดตั้งโดยช่างไฟ

### ✓ Common Mistakes

- ใช้สาย USB ชาร์จอย่างเดียว
- ต่อไฟบ้านก่อนทดสอบ Logic
- นำ Wi‑Fi password หรือ Device Key ไปใส่ในไฟล์ที่ Commit

### ✓ How to Fix

เปลี่ยนเป็นสาย USB data, ทดสอบ LED/เสียงคลิกก่อน, และเก็บข้อมูลลับในสำเนา private ของการตั้งค่าเท่านั้น
