# เปิดหน้า "สถานะโต๊ะ" ให้ลูกค้าดูผ่านอินเทอร์เน็ต (ฟรี ด้วย Cloudflare Tunnel)

หน้า `/status.html` ไม่ต้องล็อกอิน แสดงแค่ ชื่อโต๊ะ / สถานะ / เวลาที่เล่นไปแล้ว / ชื่อร้าน
(ไม่มีราคา สมาชิก หรือรายได้) ทำตามเอกสารนี้เพื่อให้ลูกค้าเปิดจากมือถือนอกร้านได้

## ระบบป้องกันที่มีในแอปแล้ว (ไม่ต้องตั้งค่า)

| ป้องกัน | ทำอะไร |
|---|---|
| Tunnel guard | คำขอที่เข้ามาทาง Tunnel เข้าถึงได้เฉพาะ `/status.html` และ `/api/public/tables` ที่เหลือ (หน้าระบบร้าน, หน้า login, API อื่น) ตอบ 404 หมด แม้ตั้ง Tunnel ผิดก็ไม่หลุด |
| Rate limit | 30 ครั้ง/นาที ต่อผู้เข้าชมหนึ่งคน (หน้าเว็บเรียกแค่ 6 ครั้ง/นาที) เกินแล้วได้ 429 หน้าจะลองใหม่เอง |
| Cache | ข้อมูลโต๊ะคำนวณไม่เกินทุก 5 วินาที ไม่ว่ามีคนเปิดกี่คน คอมร้านจึงไม่หนักขึ้น |

ปรับ/ปิด cache ได้ด้วย env `LUCKY_PUBLIC_STATUS_CACHE_MS` (ค่าเริ่มต้น 5000, ตั้ง 0 = ไม่ cache)

## วิธีที่ 1 — ลองก่อน ฟรี ไม่ต้องมีบัญชี (ลิงก์เปลี่ยนทุกครั้งที่เปิดใหม่)

เหมาะสำหรับทดสอบ เปิดแอปร้านให้ทำงานอยู่ก่อน (พอร์ต 3000) แล้วเปิด PowerShell บนคอมร้าน:

```powershell
winget install --id Cloudflare.cloudflared
```

ปิดแล้วเปิด PowerShell ใหม่ แล้วรัน:

```powershell
cloudflared tunnel --url http://localhost:3000
```

จะมีข้อความประมาณ `https://ชื่อสุ่ม.trycloudflare.com` ให้เปิดลิงก์นั้นตามด้วย `/status.html`
ทดสอบบนมือถือโดยปิด Wi-Fi ใช้เน็ตมือถือ ปิดหน้าต่างเมื่อไหร่ ลิงก์ก็ดับ และรอบหน้าจะได้ลิงก์ใหม่

## วิธีที่ 2 — ลิงก์ถาวร (ใช้จริงที่ร้าน)

ต้องมี: บัญชี Cloudflare ฟรี + โดเมนของร้าน (ซื้อประมาณ 300–400 บาท/ปี จะซื้อผ่าน Cloudflare หรือที่อื่นแล้วย้าย DNS มาก็ได้) ตัว Tunnel ไม่มีค่าใช้จ่าย
Cloudflare Zero Trust แผนฟรีอาจขอให้ใส่บัตรเพื่อยืนยันตัวตนตอนสมัคร (ไม่ตัดเงินถ้าอยู่แผนฟรี) โปรดอ่านหน้าสมัครให้ชัด

1. เข้า <https://dash.cloudflare.com> → เพิ่มโดเมน (Add a site) → เปลี่ยน Nameserver ที่ผู้ขายโดเมนตามที่ Cloudflare บอก รอจนสถานะเป็น Active
2. เมนู **Zero Trust** → **Networks** → **Tunnels** → **Create a tunnel** → เลือก **Cloudflared** → ตั้งชื่อ เช่น `snooker-status`
3. เลือก **Windows** หน้าจอจะแสดงคำสั่งติดตั้ง (มีโทเค็นยาวๆ ในคำสั่ง) ให้ **คัดลอกไปรันใน PowerShell แบบ Run as administrator บนคอมร้าน** คำสั่งนี้จะติดตั้ง Tunnel เป็น Windows Service เปิดเองทุกครั้งที่เปิดเครื่อง
   - โทเค็นนี้คือกุญแจของ Tunnel อย่าส่งในแชทหรือเก็บลงเอกสารที่คนอื่นเห็น
4. หน้าถัดไป **Add public hostname** (หรือ *Published application routes*):
   - Subdomain: `status` / Domain: โดเมนของร้าน
   - Path: `status.html` (ถ้าช่อง Path มี) — ไม่ใส่ก็ได้ เพราะแอปบล็อกเส้นทางอื่นให้แล้ว
   - Service: Type `HTTP`, URL `localhost:3000`
5. บันทึก แล้วเปิด `https://status.โดเมนของร้าน/` มันจะพาไป `/status.html` เอง
6. ทำ QR Code จากลิงก์นี้ (เว็บสร้าง QR ฟรีใดก็ได้) ปริ้นแปะที่ร้าน หรือส่งใน LINE OA

## ตรวจว่าปลอดภัยจริง (ทำครั้งเดียวหลังตั้งค่า)

เปิดจากมือถือที่ใช้เน็ตมือถือ (นอก Wi-Fi ร้าน):

- `https://status.โดเมนของร้าน/status.html` → เห็นโต๊ะ
- `https://status.โดเมนของร้าน/index.html` และ `.../api/state` → ต้องขึ้น Not found ทั้งคู่ ถ้าเห็นหน้า login ของร้านแสดงว่ามีอะไรผิด ให้ปิด Tunnel ทันที (`services.msc` → *Cloudflared agent* → Stop) แล้วแจ้งผม

## ข้อควรรู้

- ลิงก์ใช้ได้ก็ต่อเมื่อ **คอมร้านเปิดอยู่ แอปเปิดอยู่ และมีอินเทอร์เน็ต** ถ้าไม่ใช่ ลูกค้าจะเห็นหน้าผิดพลาดของ Cloudflare
- ลูกค้าในร้านที่ต่อ Wi-Fi ร้านก็ใช้ลิงก์เดียวกันได้ ไม่ต้องรู้ IP
- ปิดการเข้าถึงจากภายนอกทั้งหมด: หยุด Service *Cloudflared agent* ใน `services.msc` (ระบบร้านไม่กระทบ)
- ถ้าแอปร้านไม่ได้ใช้พอร์ต 3000 ให้เปลี่ยนตัวเลขใน Service URL ให้ตรง
